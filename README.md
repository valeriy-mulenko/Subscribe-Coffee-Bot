# ☕ Subscribe-Coffee-Bot
One of my first commercial projects


Telegram-бот для оформления и управления абонементом на кофе,админ-панелью и системой учета.

### Основные технологии:
- Python
- Aiogram 3.24.0 - асинхронный фреймворк для Telegram Bot API
- SQLite3 - встроенная реляционная база данных
### Платежная система:
- ЮКасса (YooKassa) - обработка платежей



## ✨ Возможности

### Для пользователей:
- 📝 Регистрация и профиль с настраиваемым именем
- 💳 Покупка подписки на кофе (обычная и студенческая)
- ☕ Получение кофе по подписке каждый день
- 💬 Возможность добавить комментарий к заказу
- 📊 Просмотр статуса и времени действия подписки
- 🔄 Автоматическое обновление доступности кофе

### Для администратора:
- 📊 Панель управления пользователями
- 🔍 Поиск клиентов по Telegram-никнейму
- 💰 Установка специальных цен (студенческая скидка)
- 📢 Рассылка сообщений всем пользователям
- 🎭 Рассылка стикеров
- ✅ Подтверждение выдачи кофе
- 👤 Просмотр информации о клиентах

## Требования
- Python 3.8+
- Telegram Bot Token
- ЮКасса для приема платежей
